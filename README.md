# Pinks & Blues School Management Platform

Responsive first interface foundation for the multi-school platform.

## Included
- Dashboard and navigation for the agreed school-management modules.
- Basic demo record forms, local browser storage, and JSON export.

## Not yet included
- Supabase authentication and live database connection.
- Verified role permissions and row-level security tests.
- Production deployment and end-to-end testing.

Do not enter real pupil or financial information in this prototype.
